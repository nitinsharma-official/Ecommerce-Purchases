# Ecommerce Purchases Data Analysis

## Project Overview
This project focuses on analyzing an Ecommerce Purchases dataset using Python, NumPy, and Pandas. It explores customer purchase data to understand shopping patterns and extract useful insights.

## Technologies Used
- Python
- NumPy
- Pandas
- Jupyter Notebook

## Dataset
The project uses the Ecommerce Purchases dataset, which contains customer and purchase-related information.

## Project Files
- `Ecommerce Purchases Exercise .ipynb` — Jupyter Notebook containing the analysis and exercises.
- `Ecommerce Purchases.csv` — Dataset used for analysis.

## Key Analysis
- Exploring the dataset
- Checking rows, columns, and data types
- Selecting and filtering data
- Analyzing purchase-related information
- Using NumPy and Pandas operations
- Extracting useful insights from the dataset

## Conclusion
This project demonstrates basic data analysis techniques using Python, NumPy, and Pandas. It helps build practical skills in data manipulation, filtering, and exploring ecommerce purchase data.
